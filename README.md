# Minecraft 合作生存机器人

基于 Mineflayer 的合作生存机器人。支持原版、Paper/Spigot、Fabric、Forge、NeoForge 服务器，不指定版本时自动检测服务器版本。AI 后端可选 DeepSeek、任意 OpenAI 兼容接口（含本机 Ollama）或 Claude，也可以交给外部 agent（本机 HTTP 接口 / MCP）。能自己写工作流和模组扩展。需要 Node.js 22.17 或更高版本。

扩展和接入的完整写法见 [docs/extending.md](docs/extending.md)。

## 启动与验证

```sh
npm ci --ignore-scripts
cp .env.example .env
# 在 .env 填写 AI 密钥（见 .env.example）；不填则只启用固定指令。
npm run check
npm test
npm start
```

在 `.env` 或 `config.json` 中设置目标服务器地址与端口，默认连接 `127.0.0.1:25565`。`npm start` 可在 Windows、macOS 和 Linux 上运行；类 Unix 系统也可用 `./start.sh` 启动。进程环境变量优先于 `.env`；配置由 Node 解析，不作为 shell 代码执行。机器人使用 `offline` 认证，服务器准入和账号权限由服务器管理。

## 游戏中使用

所有玩家都可以控制机器人，这是本项目的预期玩法。输入 `bot help` 查看技能；新增 `bot status` 查看当前任务及 AI 额度，`bot unmark <地点名>` 删除地点。`bot stop` 取消当前目标、在途 AI 和后续任务动作，并关闭自主规划；本地自卫与自救继续工作。已发送给服务器的操作无法撤回，旧工作仍未收尾时会拒绝新工作。

常用指令：`bot come`、`bot follow`、`bot goto x y z`、`bot mine stone 4`、`bot craft stone_pickaxe 1`、`bot smelt raw_iron 8`、`bot mark 家`、`bot go 家`、`bot goal 收集一些木头`。长期目标保留发起人；模型判断完成时会提示玩家核对游戏结果。

## 兼容性

能进的服务器：原版、Paper/Spigot、Fabric、Forge、NeoForge。`MC_VERSION` 不填时自动检测服务器版本；mineflayer 能支持的范围是 1.8.8 ~ 26.1，更新的服务器要等 mineflayer 更新，或者在服务器装 ViaVersion。

1.9.0 实测：每个服务器跑同一套 12 项检查，包括不指定版本进服、按服务器启用扩展、打招呼、扩展指令、私聊回复、查坐标、help、挖泥土、`come` 走到玩家身边、日志无报错。

| 服务器 | 版本 | 结果 |
|---|---|---|
| 原版 | 26.1.2 | 12/12 |
| Fabric | 26.1.2 | 12/12 |
| Paper | 26.1.2 | 12/12 |
| Forge 64.1.5 | 26.1.2 | 12/12 |
| NeoForge | 26.1.2 | 12/12 |
| 原版 | 1.21.11、1.21.8、1.21.4、1.21.1、1.20.6、1.20.4 | 全部 12/12 |
| 原版 | 1.20.1、1.19.4 | 12/12（首轮各有一项因地形失败：1.20.1 贴墙卡住，已改成所有版本都修正；1.19.4 漂在水里挖不到岸边泥土，已加上岸逻辑；重跑都通过） |
| 原版 | 1.18.2、1.17.1、1.16.5、1.12.2 | 全部 12/12 |

边界：
- **鞘翅自动飞行**：只在 26.1 上开。烟花校验依赖 26.1 的物品组件格式，其他版本赶路一律步行。
- **26.1 专属修正**：鞘翅动作名映射只在 26.1 生效；挖掘工具等级在其他版本上本来就是对的，不需要修正。
- **所有版本都生效的修正**：贴墙卡住、附魔读法。
- **NeoForge / Forge**：机器人以原版客户端身份进入。服务器装了必须客户端也装的模组时会被拒，日志里会说明。
- **Fabric 模组物品**：靠模组扩展里声明的组件编码识别，没声明的物品读不出来。
- **知识库**：矿石高度按 1.18 以后的地形写；1.17 及更早版本里，AI 拿到的矿物建议会不准。
- **1.12.2**：基础指令能用，但 1.13 前的物品名不一样（比如原木叫 `log`），涉及物品名的高级指令（`get`、`plan`、合成配方）不保证。

## 配置与接入（1.9.0）

- **配置**：非密钥设置可以写进 `config.json`（参考 `config.example.json`），密钥只能放 `.env`（参考 `.env.example`）。环境变量优先于文件。
- **唤醒词**：`bot` 一直有效，`MC_PREFIX=cb,小助手` 可以再加最多 4 个。
- **AI 后端**：用 `AI_PROVIDER` 选 `deepseek`、`openai`、`anthropic`、`external` 或 `off`。
- **Agent API / MCP**：设了 `MC_AGENT_PORT` 和 `MC_AGENT_TOKEN` 就会开本机接口。`npm run mcp` 启动 MCP 服务器，Claude Code、Cursor 等客户端可以直接操控机器人。
- **工作流**：`workflows/*.json` 把一串指令编排成一件事，用 `bot run <id>` 运行、`bot workflows` 列出。可以开放给 AI 调用，也可以按天黑、空闲、定时等条件自动触发。
- **模组扩展**：内置的在 `mods/`，自己写的放 `extensions/`。`.json` 只有数据（组件编码、知识、AI 提示、服务器规则）；`.js` 能注册指令和事件。扩展按服务器注册表里出现的命名空间自动启用，纯服务端模组用 `MC_MODS` 点名。
- **打招呼特效**：用 `MC_RCON_PASSWORD` 连接服务器的标准 RCON 接口；未配置或不可用时用 `/msg`。可用 `MC_SERVER_NAME` 设置欢迎语中的服务器名，默认不显示服务器名。

共享背包与共享血量规则由可选的 `shared-world` 扩展提供，默认关闭；仅在目标服务器确实启用这些规则时设置 `MC_MODS=shared-world`。

## 本地自主日程

本地日程默认关闭。设置 `MC_AUTONOMY=on`（或 `config.json` 里 `autonomy.enabled`）后，机器人在**完全空闲**时按固定规则做下一步，不调用模型，每次动作一行 `[auto]` 审计日志。

- **顺序**：附近有敌对生物 / 血量 ≤6 / 忙 → 不动；饱食 ≤14 且有吃的 → 吃；天黑且离家 >16 格 → 回家；木头 <16 → 砍 16；石头 <32 → 挖 32；都不缺 → 待机。不会随机游走。
- **预算**：`MC_AUTONOMY_TICK`（默认 5000 毫秒）是检查间隔，`MC_AUTONOMY_MAX`（默认 60）是每小时最多动作数。成功和失败都记账；被玩家抢占或停止的动作记录为 `interrupted`，不记账、不增加失败退避。超预算就停到下个窗口。
- **不抢玩家**：自主动作优先级最低（`routine`）。玩家指令（`player`）会抢占并让日程让路；被抢占的日程不算失败，下一轮重新评估。
- **`bot halt`**：只停自主并取消正在进行的自主动作，保留目标、排队和玩家正在下的活；`bot stop` 仍是清空一切。`bot status` 会显示 `自主:开(本小时剩N/M)`。
- **`bot get` 续做**：数量始终表示背包中的总目标；重下同一条指令会按当前背包重新规划，已有部分直接复用，物品被拿走后也会补足。

当前边界：日程只覆盖已有技能（吃/回家/砍树/挖石头），只有每小时动作数预算，没有方块数或资源消耗预算，也不识别玩家建筑和领地；只应在允许机器人采集附近资源的环境启用。尚无项目系统、世界模型和区块记忆。

## 自动赶路（1.6.0）

现在可以直接说 `bot 回家`、`bot 去 300 64 0 等我`，或让 AI 在长期目标里前往已知地点。`goto/go/come` 共用同一套交通选择，不需要另输 `fly`：

- 32格内优先步行；96格及以上，在装备、耐久、烟花、健康和起飞净空核验通过后优先鞘翅。
- 32–96格通常步行；只有已加载近处地形明确存在水障或明显高差，才考虑飞。未知方块不被当成安全或障碍证据；远处目标尚未加载仍可使用现有长途飞行。
- 飞行沿用1.5的烟花/耐久预检公式和多段能力，不增加新的短途距离上限。没有鞘翅、烟花不够、状态不好或起飞受阻时会选择步行，并说明原因。
- 胸槽空时可自动装备背包里的合格鞘翅；胸槽已有普通胸甲时保留胸甲走路，AI不能用先装备鞘翅再赶路绕过此保护。玩家仍可明确输入 `bot equip elytra` 换装。
- 起飞前重查物资和装备。自动找起飞点的步行最多2次、累计目标偏移64格；连续两段飞行没有有效接近目标会终止重飞。最多8段，仍共用同一个任务时限与取消代际。
- 正常落地后按原始坐标和高度核对，不把飞行返回的宽容差当作已经到达；必要时进行一次步行对接。取消、死亡、低血量、超时或尚未确认落地时不会接着步行。

`bot walk x y z` 或 `bot walk 家` 明确只走地面，失败不会自动改成飞行；自然语言明确说“只步行／全程走路／不要飞”也会保留步行约束。`follow`以及挖矿、开箱、建造等技能内部的靠近动作仍使用原来的局部寻路，避免无意消耗烟花。

AI收到的是实际交通结果：选择原因、降级原因、交通方式、烟花耗用和结束位置。降级步行后真正到达属于成功，交通失败也会计入长期目标的失败记忆。手动 `bot fly` 仍保留原有显式飞行功能。

数量必须为 1–64 的整数，狩猎最多 8 只；省略 `drop/deposit/withdraw` 数量表示全部。支持 `minecraft:stone` 自动规范成 `stone`，其他模组 namespace 保留，但不能因此推断未知模组配方或容器已受支持。地点最多 64 个，名称为 1–32 个中文、字母、数字、下划线或短横线；同名可更新。

普通任务最长 3 分钟，烧炼最长 12 分钟。AI 默认全局最多每分钟 6 次、每小时 120 次请求，可用 `AI_RPM`、`AI_RPH` 调整；失败和取消也计入额度。这些是单个进程的请求上限，重启会重置计数。每位玩家独立保留最多 10 条历史，最多 32 个会话；长期笔记仍是共享记忆。启用 AI 后，玩家聊天、地点、库存、附近环境及共享笔记会发送至所配置的 AI 后端。自主模式默认关闭，使用 `bot auto on` 显式启用。

聊天输出始终按纯文本处理，斜杠会被转义为可见文本。AI 只能执行固定动作，不能生成或执行 JavaScript；丢弃共享物品必须由玩家直接使用 `bot drop <物品> [数量]`，AI 不会自行丢弃。

## 建筑

`bot build <模板> [m=材料] [at=x,y,z] [f=north|south|east|west] [clear=1]`：模板有 tower、wall（w= h=）、floor（w= l=）、stairs（n=）、pyramid（n=）。默认建在机器人面前 3 格，朝它面对的方向。

- `bot materials <模板>` 先看材料。开工前核对材料和占位：有方块挡路或材料不够就不开工；`clear=1` 只会挖天然地形（泥土、石头、树叶等），不碰木头和别人的建筑。
- 每块放完读回校验，朝向不对会挖掉重放；完工后再读一遍真实世界。中途 `bot stop` 或重启后，重新下同一条指令会续建，已放对的跳过。
- 高处够不着时用多余的泥土/圆石垫立柱，完工自动拆除并捡回；建筑材料不会被拿去垫脚。
- 绝不放 TNT、岩浆、火、命令方块等；AI 不能用钻石块等稀有材料，也不能用 clear，一次 fill 不超过 256 格。

其他：`bot fill x1 y1 z1 x2 y2 z2 <方块> [hollow]`、`bot bridge [长度] [方向] [材料]`（边走边铺，遇岩浆停）、`bot pillar [高度]`、`bot copy x1 y1 z1 x2 y2 z2 <名字>` + `bot paste <名字> [at=] [f=]`（可旋转，容器内物品不复制）、`bot undo`（只拆上次蓝图放的且未被改动的方块）、`bot blueprints`。`.schem`（Sponge v2/v3）放 `data/schematics/` 后可 `bot paste`。

## 红石

- 搭建：`bot circuit <lamp/not/or/and/memory/gate/autodoor/clock/fastclock/nightlight/dropbox> [at=] [f=]`，搭完自动按拉杆读状态做功能自检（nightlight、dropbox 无自检）。`bot wire x1 y1 z1 x2 y2 z2` 拉同高度红石线，每 14 格加中继器。
- 操作：`bot use [x y z]`、`bot door open|close`、`bot repeater x y z <1-4>`，操作后读回状态。
- 读线路：`bot rs [半径]`、`bot rstrace x y z`（走线、电源、负载、断头）、`bot rsdiag x y z`（灯/活塞为什么没动）。追踪模型只含红石线、台阶、中继器和比较器，不模拟强充能穿方块等全部机制。

## 跑酷

`bot parkour x y z [risk]`、`bot parkour check x y z`：走、上台阶、下落、1~3 格沟、跳上/跳下、斜跳、爬梯子。起跳前用物理引擎模拟，模拟落不到就不跳；空中按预测落点闭环修正。沟下有岩浆、虚空或未加载区块一律不跳（risk 也不行），`risk` 只放宽沟下落差；血量 ≤10 不跳。`bot goto`/`bot come` 普通寻路走不通时会自动试跑酷路线。

不支持：跳过 4 格及以上的沟、靠墙角绕跳（neo）、滑块/粘液块弹跳。半砖、栅栏等非整格落点未做实机覆盖。

## 实机测试

`scripts/lab/` 提供连接隔离本机测试服的场景脚本，通过 RCON 读取服务器状态。运行前显式设置 `LAB_CONTAINER`；端口、版本与输出目录等参数见 [实机测试配置](scripts/lab/README.md)。脚本会修改测试世界，请使用可丢弃的隔离环境。

`existing-features.js` 回归已有功能，`new-capabilities.js` 测建筑红石跑酷，`complex.js` 测组合场景和 AI 指令链路（用 `fake-deepseek.js` 回放固定响应，不代表模型决策质量）。

## 兼容性探测

```sh
MC_HOST=127.0.0.1 MC_PORT=25565 npm run probe:registry
```

探测仅进行 Fabric 配置握手，拿到注册表后断开，不进入游戏。离线测试使用由公开原版数据和示例模组条目生成的注册表样本，校验 SHA-256、解析顺序、扩展启用及未知组件处理；另覆盖截断、计数放大、畸形 AI、聊天命令边界、取消竞态和持久化失败。样本生成器为 `test/fixtures/generate-fabric.js`，不包含服务器抓包。替身测试不能证明真实采矿、合成、战斗等完整游戏行为，实机覆盖见“实机测试”。

## 鞘翅赶路（1.2.0）

穿好鞘翅、带够普通烟花，再明确下令：

```text
bot fly 300 0        # x z，不给高度，落地高度由地形决定
bot fly 300 64 0     # x y z
bot fly 家
bot stop
```

手动 `fly` 保留原有功能；AI通过 `goto/go/come` 的自动交通入口使用同一套鞘翅控制。`walk`可明确保持地面交通。

主世界生存模式下不限距离（上限 6000 万格），未生成的区块边飞边等。实测 6000 格约 55 枚烟花、5 分钟，约合每枚 100 格。烟花只认无爆炸、飞行时间 1 的。预检要求鞘翅耐久至少 120、血量至少 16/20、饱食至少 14/20，并带够这段距离的烟花，不够会先报数拒飞。普通胸甲不会被自动脱下。

- 起飞：脚下要有 5×5 净空，树林和屋里会先走到附近开阔地，找不到就朝目标走一段再找；到了会再验一次。站在坑底走不出来时换成能挖能搭的寻路。落水时先浮上水面、游到最近的岸（看不到岸就朝目标游）再起飞。
- 途中：地形和墙会抬高巡航高度越过去；实在要撞才就地降落，然后接着飞，最多 8 段。耐久见底时空中换背包里的备用鞘翅，一只满耐久的鞘翅约飞 7000 多格。
- 落地：优先平地；目标附近没有（大海、密林）就就地降下去，落水和落树冠都不致死。之后步行对接，落在树上下不来时允许挖路和垫方块；走不通而且还差 12 格以上就再飞一段。
- 到达：读回坐标，步行对接后在 2 格内、直接落地在 6 格内才报告到达。

起飞前不再要求确认有备用落点，这是为了能飞向未知区域，代价是没有平地时只能硬着陆到水面或树冠。

`bot stop` 立即取消航线和后续烟花，只保留无烟花降落控制，落地后报告位置，落地前不接新任务。2 分钟仍确认不了落地时显示 `UNCONFIRMED_AIRBORNE`，停止主动控制，只等落地或断线。飞行期间战斗、进食、看人、捡物和其他走路模式不抢控制。突然出现的玩家建筑、共享背包被别人改动仍可能导致提前落地，不保证任何地形都能一次到达。

## AI 长指令和意图

不是固定指令的 `bot ...` 交给 AI 理解。

- 长指令：一句话说好几件事时，AI 先列计划，没做完（`done=false`）程序就带着结果继续下一步，最多 12 轮，`bot stop` 随时取消。`bot goal` 仍是 30 轮的长期目标。
- 输出出错：模型输出没通过校验时，日志记录 `[ai] 输出没通过校验，重试: <原因>`，并把原因告诉模型重写一次。整批动作仍然先校验再执行，不会只执行一半。
- 条件批量挖：`bot excavate dirt,grass_block r=32 above=76`，只收土、石、沙这类天然方块，单次最多 512 格，从上往下挖，先报数量。它不认识玩家建筑，范围内用同种方块盖的东西也会被挖，所以范围要给准。
- 明确要飞：玩家原话有“飞回/飞到/飞去/用鞘翅”时，AI 的 `goto/go` 改走 `fly`，这句话视为授权使用烟花；说“别飞”时只走路。
- 打史莱姆：`bot hunt slime`。

## 本地同伴行为

- `bot follow [2-8]`：可设置跟随距离。目标实体被替换会重新绑定；看不到时原地等待，60秒内重新看到便恢复，否则停止。跨维度或 `bot stop` 后不追旧目标。
- `bot scan`：读取位置、维度、健康、饱食、氧气、装备、背包空位和跟随状态。
- `bot advice`：本地规则给出食物、工具、护甲、背包和夜间补给建议，不调用AI，不自行花费物品。
- `bot lastdeath`：查看本次机器人进程启动后最近的死亡坐标，不自动冒险取回物品。
- 脱困最多连续尝试3次；任务换代重置预算，吃饭/容器/战斗/飞行暂停不被当成卡住。
- 可选捡物的等待绑定单个物品，先验证不用挖掘搭方块即可到达；失败或超时对象进入冷却。该模式仍默认关闭。
- `bot mode elbow_room on`：开启空闲让位。只在不跟随、不站岗、不战斗、不做任务时给贴近玩家让出两格安全地面，受冷却和短超时约束；默认关闭。

本轮借鉴范围、固定提交、采纳与舍弃理由见 [UPSTREAM_REFERENCES.md](UPSTREAM_REFERENCES.md)，代码适配归属见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 第二批能力（1.3.0）

参考 AltoClef、Baritone、Mindcraft、Voyager、Odyssey 和 mineflayer 官方示例后，挑了在共享背包下也安全的部分：

| 指令 | 作用 |
|---|---|
| `bot get <物品> [数量]` | 万能获取：自动规划 挖→烧→合成（缺镐先做镐，只挖天然方块，不拆建筑）；某步失败按当前背包重新规划，最多 3 轮 |
| `bot plan <物品> [数量]` | 只看规划步骤，不执行 |
| `bot farm [半径]` | 收成熟作物并补种，空耕地也种上；寻路避开耕地不踩坏 |
| `bot breed <动物>` / `shear` / `milk` / `fish [次数]` | 繁殖、剪羊毛、挤奶、钓鱼（看浮漂 biting 元数据收竿） |
| `bot tunnel [长度] [东南西北]` / `digdown [深度]` | 1x2 隧道（每 8 格插火把）、向下挖；挨着岩浆/水、脚下悬空就停 |
| `bot torch` / `explore <方块或生物>` / `dump` | 插火把、走远探索直到看见目标、杂物存箱 |
| `bot inspect <物品>` / `try <模组物品>` / `tip [关键词]` | 查物品信息和知识、亲手试模组物品（结果记进 data/itemnotes.json）、查生存技巧 |
| `bot replan on/off` | 直接指令失败后是否让 AI 接手重新规划（默认开） |

常驻模式新增 `sleep_with_players`（默认开）：有玩家上床时空闲的机器人也找空床睡，帮多人服跳过夜晚。自救模式会躲开头顶掉落的沙子砂砾。

**AI 智能体**：AI 可返回 `plan`（3–8 步计划）和 `check`（完成时本地核对的物品数量）。每个动作单独记录结果，一个失败就停下后续动作交给 AI 重新规划；反馈里带背包变化。长期目标（`bot goal`）每轮带上计划、最近进展、反复失败的动作和状况变化（死亡、卡住、超时、核对失败），死亡/卡住/超时不再终止目标；目标存盘在 data/goal.json，重启后 2 小时内会接着做；AI 额度用完时等待而不是放弃。直接指令失败时 AI 以最多 8 轮的小目标接手。

**知识**：`knowledge.js` 收录原版生存技巧（矿物高度、工具、怪物、农业、下界等）；模组用法由启用的扩展提供，内置支持精致存储、传送石碑、Lootr、Carry On、FTB Ultimine 等。按关键词挑选相关内容放进 AI 提示。

**配合玩家**：私聊不用加 bot 前缀；聊天里叫到机器人名字/"机器人"会回应；忙时新指令排队（最多 3 条）；超过 40 秒的活结束后点名告诉下指令的人；缺材料会请玩家帮忙；跟随对象和 12 格内的队友被怪贴身时会去帮忙；AI 能看到附近玩家的方向、距离和手持物品。

**战斗**：修复僵尸马骑士等骑乘怪（骑手坐标从坐骑同步）；新增 parched、breeze、ravager 等敌对生物；幻翼只在俯冲到身边时砍；血少撤退时对骷髅举盾，吃东西时不举盾。

## 行为修正（1.8.2）

- 聊天：私聊来的查询指令（pos、inv、status…）私聊回，不再公屏广播；长列表在逗号后分段，不把 `netherite_chestplatex1` 拆成两条；`status` 的 AI 额度改成人话。
- 下界：有防火效果时只躲岩浆本身；赶路途中踩过岩浆块不打断寻路（以前反复“跑开”把目标顶掉，整趟放弃）。
- 挖矿：背包满时直接说背包满了（以前重试 100 秒后报“找不到能走到的方块”），规划器也不再因此换原料；挨着水的方块放到最后挖；挖不够数量说“只挖到 x/y 个”；放弃一块时日志记下寻路现场（`[collect]`）。
- 水里寻路：站在水坑底（脚下是实心地面）也允许挖和垫出去，以前一律禁掉，1x1 水坑里一步不动。
- 战斗：撤退、逃跑时也不在受伤时换手吃东西（以前被僵尸追着吃东西超时后被打死），残血由战斗循环先撤到安全处再吃。
- 到达判定：水平到了、高差 1.5 格内算到（玩家给的 y 常因水面、半砖差一格，以前报“未到目标”）。

## 稳定性修正（1.8.1）

- 日志：启动时预加载 `log-time.js`，输出带本地时间；连不上服务器只记一行原因，不再打整段堆栈和 physicTick 弃用警告。
- 断线重连：没进过服就按连续失败次数退避（15、30、60…最多 300 秒）再退出，外部进程管理器可负责重启；计数在 `data/reconnect.json`，进服后清零。
- 垫高：站在耕地、土径这类不满一格的方块上也能 `pillar`（以前把方块放进耕地本身那格，被服务器拒绝）。
- AI：只写 `cmd` 的无参动作自动补 `args: []`，仍走同一套校验；提示里写明 `pillar` 最多 32 格，少一轮返工。

## 经验和箱子记忆（1.8）

- 经验：长期目标结束后，程序记下做成没有、用过的动作、卡在哪里（`data/experience.json`，最多 50 条，同一目标只留最新）。下次遇到相似目标放进 AI 的 state。玩家取消的不算。`bot lessons` 查看，`bot lessons clear` 清空（AI 不能清）。
- 箱子：开过的原版箱子和木桶会记住内容（`data/containers.json`，最多 40 个）。`bot chests [物品]` 查，`bot chestscan [半径]` 走一遍附近的箱子（只看不拿），`bot fetch <物品> [数量]` 去 128 格内记得的箱子拿，到了以当场内容为准。`get` 不会自动拿箱子。

## AI 智能体（1.7）

- 模型默认 `deepseek-flash` 并开启思考；`DEEPSEEK_MODEL` 可换 `deepseek-v4-pro`，`DEEPSEEK_THINKING=off` 关思考。接口拒绝思考参数时自动退回普通模式。
- 任务清单由程序记账（`agent.js`）：漏写的任务不会消失，还有没做完的项时不收工；`verify` 条件（物品、位置、方块、清空范围）由程序核对，3 次不过标失败。
- 模型能看到说话人的坐标和他看着的方块、最近聊天和最近执行结果。
- 忙时：问进度当场回答，“算了/停下”立即停，其他新要求并进正在跑的任务；固定指令仍排队。
- 长任务：请求失败会退避重试（连续 4 次才放弃），同样动作几轮没变化会换法并自停。
- 评测真实模型：`DEEPSEEK_API_KEY=... node scripts/lab/intent-eval.js`（加 `--off` 对比不思考）。


### 长期世界记忆与结构候选

设置 `MC_MEMORY_WORLD` 为一个稳定世界标识（例如 `coop-2026`）后，机器人会独立于自主模式被动记录附近已加载的门户、结构特征候选、设施、矿点和岩浆。世界重置时换标识；没有标识时不保存新自动事实。`MC_MEMORY_OBSERVE=off` 或 `bot memory off` 仅暂停自动观察，已有记忆仍可查询；不会开启自主模式。

- `bot memories [关键词]`：检索，明确显示维度、来源、候选/陈旧状态和 ID。
- `bot memory status / on / off / flush`：检查状态、暂停/恢复观察、立即写盘。
- `bot memory name <ID> <名字>`、`pin/unpin <ID>`：人工命名和保护记录。
- `bot memory invalid <ID> [原因]`、`forget <ID>`：报告失效或删除，防止扫描马上重建。
- `bot memory remember <structure/place/portal/resource/facility/hazard> <类型> [名字]`：在机器人当前位置登记明确的玩家报告。
- `bot memory confirm <连接ID>`：人工确认一条候选门户边；这不是服务端认证。

v1 的七种结构检测规则和验证边界见 [长期记忆设计](docs/long-term-memory.md)。客户端普通区块没有自然生成结构名称标签，因此不会把玩家建筑误宣称为已确认自然遗迹；门户接触后发生的传送也只生成有向候选，不能自动排除管理员传送。此版本不自动找门或跨维度赶路。

设置世界标识后，新地点、箱子缓存和经验使用世界专属文件，旧文件原样保留、不自动迁入。需要在正确世界重新 `mark`/开箱或明确人工报告。Agent 在规划前检索记忆、执行后用程序核验；未知/陈旧结果不作为已验证成功配方。自动观察最多5秒批量写盘，正常退出会 flush；`memory status` 可查看待写与降级错误。
