## 自动化覆盖

- 真实临时文件：atomic rename、权限/容量/字节上限、flush与重启、损坏/未来schema/世界不匹配只读、失败不发布人工更改。
- 门户乱序方块形成多簇后合并、旧ID别名、连接端点规范化/去重、人工确认与失效、删除墓碑和明确玩家恢复。
- 自动结构永为候选、跨world和实际custom level隔离；人工命名/pin保护、TTL、暂停后仍可检索。
- 观察预算、快速末地门接触、位置稳定、同level折跃、死亡/已知TP抑制、未知区块不作销毁、重启后复核锚点、历史空气点不得作出口。
- 真实bot入口（网络/模型边界替身）：换level取消旧响应/跟随/裸坐标队列、同type customlevel、私聊管理、外部Agent不能假装人类确认、新scope不默迁旧数据。
- 行动三态、当前条件不等于Bot因果；一项已核验不能让整个未核验清单写成成功；合法飞行落点不被统一距离规则误判。
- 同level stop允许关闭自己持有的窗口；跨level或旧窗口ID复用不关闭新窗口；先stop后换level仍拦旧关闭包；旧craft超时不得unscoped关闭新窗口。

## 已知边界

- 未完整测试所有七类自然生成结构；白名单规则由受控特征和单元测试验证，输出始终是候选。
- 管理员在门内TP与真实门传送从普通客户端不能绝对区分，因此自动边不能升级为确认事实。
- 首次使用需设置稳定的`MC_MEMORY_WORLD`；世界重置时轮换。旧记录原文件保留，未隐式迁入新scope。
- 自动写盘最多有五秒待写窗口；SIGKILL可能丢这段新观察。人工管理立即原子写盘。
- 大于四格半径的清空区域条件当前保持unknown；不把部分加载的空查询当作已清空。
- 生产模组服的完整自然玩家/AI使用验收留待评审合并后的部署阶段；本PR不启用生产自主。
